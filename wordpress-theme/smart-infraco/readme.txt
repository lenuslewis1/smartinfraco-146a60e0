== Description ==

Installable WordPress theme for the Smart Infraco public website.

The theme packages the production React application, responsive layouts,
animations, media assets, navigation routes, Articles archive, webinars,
service pages and contact experience. Node.js is not required on the server.

== Installation ==

1. In WordPress, go to Appearance > Themes > Add New > Upload Theme.
2. Select smart-infraco-wordpress-theme.zip.
3. Click Install Now, then Activate.
4. Go to Settings > Permalinks and click Save Changes once if a host-level
   cache prevents a design route from loading.

== Notes ==

This release is a design-preserving hybrid theme. Website content is compiled
from the supplied Smart Infraco React source rather than WordPress block-editor
content. The WordPress administration area remains available normally.
